# Proposed roadmap

These are ideas, not completed features or delivery promises.

- Collect real user feedback and publish reproducible bug fixes.
- Streaming validation with a configurable cap on reported issues.
- Composite uniqueness rules spanning multiple columns.
- Polish-language report messages.
- Optional HTML reports with safe escaping.

The current implementation is version 0.1.0 and has no asserted user base or download metrics.
