# Contributing

Open an issue describing the actual use case before proposing a large feature. Bug reports should include a minimal synthetic CSV, the rules, expected result, actual result, and Node.js version. Do not upload private exports or credentials.

Run `node --test` before submitting a pull request. Add a regression test for behavior fixes. Keep runtime dependencies at zero unless a clear benefit is discussed. Update the README when changing command-line options or validation semantics.

The maintainer should review each change and test it before merging. Automated suggestions are not a substitute for review.
